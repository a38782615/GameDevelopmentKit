# 战斗胜利奖励技能经验

## 修改内容

- 在 `MapGenComponent` 中记录当前战斗是否已经发放胜利奖励。
- 每次创建本地战斗单位时重置结算状态。
- 怪物死亡并从 `UnitComponent` 移除后检查场上是否仍有怪物。
- 最后一个怪物被移除时，为玩家增加 `100` 点 `SkillExp` 并立即保存玩家数据。
- 在第一次异步保存前设置已结算状态，避免多个怪物同时死亡造成重复奖励。
- 记录胜利奖励及累计技能经验日志，便于运行时验证。

## 验证结果

- `dotnet build Game.ET.Code.HotfixView.csproj --no-restore` 构建通过，0 错误。
- 通过 Unity Agent Bridge 停止 Play Mode 后触发 generation 34 重编译。
- Unity 编译结果为 0 错误、24 个既有警告，本次改动未新增编译诊断。
- 未自动运行完整战斗，运行时可通过 `Battle victory rewarded SkillExp=100` 日志确认奖励链路和触发次数。
