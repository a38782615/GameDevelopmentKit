# UIFormBag1 跨 Grid 拖拽

## 实现内容

- 为 `UIFormBag1` 的循环列表 item 模板新增 `BagItemDragHandler`。
- 拖拽时创建不阻挡射线的半透明视觉副本，原 item 保持在循环列表布局中。
- `Grid0` item 仅在释放到 `Grid1` 区域时调用 `DropToBag`。
- `Grid1` item 仅在释放到 `Grid0` 区域时调用 `BagToDrop`。
- 在同一 Grid 或 Grid 外释放时不修改数据；迁移完成后刷新两个循环列表。
- item 被循环列表回收或 UI 关闭时清理拖拽回调和用户数据引用。
