# UIWidgetMap加载战斗

## 改动

- 新增 `UIWidgetMapSystem`，打开地图 Widget 时动态扫描地图根节点下的 `P0`、`P1`、`P2` 等按钮节点。
- 按节点名解析 `SubLevel`，并结合 `FightComponent.CurrentMap` 匹配 `Stages` 表中的 `Level` / `SubLevel`。
- 存在对应关卡时显示并绑定按钮，点击后加载对应战斗；没有对应关卡时隐藏按钮。
- `FightComponentSystem` 改为按当前地图和子关卡读取 `Stages`，加载前清理已有战斗单位，避免重复加载冲突。

## 验证

- 已通过 AIBridge 执行 Unity 编译检查。
- 编译结果：0 error，0 warning。
