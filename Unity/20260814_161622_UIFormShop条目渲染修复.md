# UIFormShop 条目渲染修复

## 根因

`ShopItemRender` 依赖 `UIWidgetShopItem` 先完成打开并注册到 `ItemWidgets`，但滚动列表的 `itemRenderer` 不保证该注册时序，导致条目 Transform 已存在时仍可能找不到对应 Widget。

## 改动

- 新增 `ShopItemTempLogic`，承载商店条目的视图与数据。
- `ShopItemRender` 直接从复用条目获取现有 `MonoUIShopItem` CodeBind 根并调用 `ItemRender`。
- `ItemRender` 通过生成的绑定属性刷新名称、数量和图标状态，不再依赖 `ItemWidgets` 查询。

## 验证

- 定向静态检查由 `hasDirectItemRender=False, rendererUsesItemWidgets=True` 转为通过。
- Unity 编译通过，0 个错误、0 个警告。
- Unity Console Error 日志为空。
