# UIFormMain Button Trigger

## Task

Implement UIMain button click triggers in `UIFormMainComponentSystem`, using `UIWidgetBtmBarSystem` as the reference pattern.

## Changes

- Bound `GMapExButton`, `SMapExButton`, and `ShopExButton` when `UIFormMain` opens.
- Removed those listeners when `UIFormMain` closes to avoid duplicate registrations.
- Added shared button binding and async click handling. Clicks currently log `[UIMain] Click {actionName}`.
