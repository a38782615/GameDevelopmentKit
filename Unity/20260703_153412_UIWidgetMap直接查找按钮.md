# UIWidgetMap直接查找按钮

## 修改内容

- 调整 `UIWidgetMapSystem` 的地图按钮缓存流程：先根据当前 `FightComponent` 刷新 `StageSubLevels`，再按 `P{subLevel}` 直接查找对应按钮节点。
- 移除遍历 `Map` root 子节点收集按钮的逻辑，`StageButtons` 与 `StageSubLevels` 保持同索引对应。
- 关卡变化或 `FightComponent` 不存在时，先清理旧按钮事件与显示状态，再重建缓存，避免旧点位残留。
- `Map` 根节点定位改为 `root.Find("Map")`，不再手动遍历 root 子节点。

## 验证

- 已停止 Unity Play Mode。
- 已执行 Unity 编译检查，通过且无错误、无警告。
