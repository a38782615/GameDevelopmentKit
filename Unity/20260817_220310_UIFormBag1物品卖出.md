# UIFormBag1 物品卖出

## 完成内容

- `UIFormBag1` 记录当前选中的储物袋物品，并根据选择状态控制卖出按钮。
- 每次点击卖出按钮出售 1 个物品，单价读取 `DTItems.Diamond`，所得灵石累加到 `PlayerData.Diamond`。
- 堆叠数量归零时从库存移除物品；装备中的最后一个物品被卖出时同步刷新装备属性。
- 使用 LiteDB 事务同时保存玩家灵石和库存物品，存档失败时回滚内存中的数量、灵石及库存位置。
- 接入卖出按钮 Prefab、CodeBind 字段、本地化和字体资源。

## 验证结果

- 已停止 Unity Play Mode。
- AIBridge `compile unity --raw --timeout 120000` 通过，0 Error、0 Warning。
- AIBridge Unity Console Error 日志为空。
- 本次涉及的 C#、Prefab 和绑定文件未发现 Unicode 替换字符，中文编码正常。
