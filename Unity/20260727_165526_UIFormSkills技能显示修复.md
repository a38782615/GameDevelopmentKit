# UIFormSkills 技能显示修复

## 修改内容

- 参考 `UIFormBag1System.BagItemRender`，使用 `SkillTempLogic` 承载循环列表项数据并统一渲染。
- 三个技能列表分别显示已学习、已装备被动和已装备主动技能。
- 技能项显示技能等级，并复用统一的技能按钮图片模板。
- 点击技能项后执行装备或卸下、保存 `PlayerSkillData` 并刷新列表。
- 使用 `SkillTemp_ExButton_Image` 作为循环列表模板，移除旧的独立 `MonoUISkillsItem` 方案。
- 补充返回按钮绑定与关闭时的监听、列表 Renderer 清理。

## 验证结果

- Unity 运行时打开 `UIFormSkills` 后，已学习列表显示 1 项，主动装备列表显示 1 项，被动装备列表显示 0 项。
- 运行时生成的技能项均使用 `SkillTemp_ExButton_Image` 模板。
- 停止 Play Mode 后通过 AIBridge 执行 Unity 编译：0 error，0 warning。
- 本次 C# 文件通过 UTF-8 与乱码标记检查。
