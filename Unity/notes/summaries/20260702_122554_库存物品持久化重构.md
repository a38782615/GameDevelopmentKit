# 库存物品持久化重构

## 修改内容

- 移除 `InventoryData.NextItemId`，`InventoryData` 只作为运行时缓存。
- `InventoryDataComponent` 加载时从 `InventoryItemData` 集合重建背包和装备缓存。
- 保存库存时逐条持久化 `InventoryItemData`，并删除缓存外的旧物品记录。
- 新增物品 ID 改为 `IdGenerater.Instance.GenerateId()`。
- 兼容旧版 `InventoryData` 存档：首次加载时迁移旧缓存中的物品数据，然后删除旧文档。
