# 搜索目标阵营标签

- 需求：新增 `campType.SelfCamp` 本阵营、`campType.EnemyCamp` 敌对阵营标签，并让搜索目标节点在目标标签与排除标签中识别阵营标签。
- 处理：在 `GameplayTagsAsset` 与 `GameplayTagLibrary` 中加入 `campType` 标签树；搜索目标过滤时将 `campType.SelfCamp` / `campType.EnemyCamp` 作为相对施法者的虚拟标签判断，普通标签仍按 `OwnedTags` 匹配。
- 语义：目标标签保持“任意命中即通过”；排除标签保持“任意命中即排除”。阵营标签无法解析施法者或候选目标 Unit 时不命中。
- 验证：Unity 编译通过，Console 无 Error。
