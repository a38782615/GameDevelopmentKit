# Toolbar显示修复

- 问题：Unity 6000.3.17f1 下原 `ToolbarExtension` 挂载旧 `UnityEditor.Toolbar` / `ToolbarZone*` 路径后按钮不可见，右侧绝对定位菜单也会落到 Dock 覆盖区域。
- 处理：改为直接挂载 `UnityEditor.MainToolbarWindow.rootVisualElement`，使用单个 `GameDevelopmentKitToolbar` 容器承载可见按钮，并将右侧工具统一放入 `Tools v` 菜单。
- 兼容：保留旧 `[Toolbar]` 属性扫描，并以 `IMGUIContainer` 渲染旧式无参静态 GUI 方法；新增 `[ToolbarButton]` 和 `[ToolbarDropdown]` 用于稳定声明按钮与下拉菜单。
- 验证：Unity 编译通过，Console 无 Error；截图确认 `Scene v`、`Tools v`、`ETUI-Model`、`ETUI-Hotfix`、`UI-Res`、`ETReload`、`ETCompile`、`Launcher` 已显示在主 Toolbar，用户确认菜单可弹出。
