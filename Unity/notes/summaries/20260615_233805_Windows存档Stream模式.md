# Windows 存档 Stream 模式

## 变更

- Windows 平台下 `ArchiveComponent` 改为通过 `new LiteDatabase(Stream stream, BsonMapper mapper, Stream logStream)` 打开 LiteDB。
- 新增 `DatabaseStream`、`LogStream` 和 `UseStreamDatabase` 状态，组件销毁时显式释放外部 Stream。
- Windows Stream 模式保留密码支持：有密码时使用 LiteDB `AesStream` 包装 data/log 文件流。
- Stream 模式下 `Rebuild` 不再调用文件名模式的 `LiteDatabase.Rebuild`，改为 `Checkpoint`，避免无效重建语义。

## 验证

- 已通过 `AIBridgeCLI compile unity --raw --timeout 180000`，Unity 编译错误数为 0。
- 已检查本次 Archive 相关代码，无尾随空格和中文乱码残留。
