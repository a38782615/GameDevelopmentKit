# CanvasScaler 匹配规则调整

## 变更内容

- 在 `Assets/Scripts/Library/UGF/UnityGameFramework.Extension/Runtime/Screen/ScreenComponent.cs` 中新增统一判断方法 `GetCanvasScalerMatch(float width, float height)`。
- 规则为：当 `宽:高 >= 750:1335` 时，`CanvasScaler.matchWidthOrHeight = 1`；否则设为 `0`。
- `ScreenComponent` 新增运行时监听逻辑：当 `Screen.width`、`Screen.height` 或 `Screen.safeArea` 变化时，自动刷新 `matchWidthOrHeight` 和缓存的屏幕数据。
- `Assets/Scripts/Game/Builtin/BaseBuiltinForm.cs` 也新增了运行时检测，在内置界面分辨率或安全区变化时同步刷新 `CanvasScaler.matchWidthOrHeight`。
