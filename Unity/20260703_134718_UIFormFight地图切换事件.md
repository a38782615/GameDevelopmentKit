# UIFormFight地图切换事件

## 改动

- 为 `UIFormFight` 的 `PreExButton`、`NextExButton` 绑定异步点击事件。
- 点击后更新 `FightComponent.CurrentMap`，并按当前地图重新加载 `UIWidgetMap`。
- 切换前移除旧地图 Widget，避免多个地图 UI 叠加。
- 增加 `CurrentMapWidget` 和 `IsSwitchingMap`，用于记录当前地图 Widget 和防止连续点击重入。

## 验证

- 已通过 AIBridge 执行 Unity 编译检查。
- 编译结果：0 error，0 warning。
