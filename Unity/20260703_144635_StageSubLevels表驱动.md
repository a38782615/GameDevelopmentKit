# StageSubLevels表驱动

## 改动

- `StageSubLevels` 改为按当前 `Stages.Level` 从配置表生成，数量由当前 Level 下的表行决定。
- `StageButtons` 继续缓存 `ExButton`，新增 `StageButtonSubLevels` 保存按钮节点自身对应的 SubLevel。
- 绑定时用按钮节点 SubLevel 匹配表驱动的 `StageSubLevels`，无配置的按钮隐藏。
- 新增 `FightComponent.GetCurrentStageLevel()`，避免 UI 系统直接访问 `FightComponent` 字段。

## 验证

- 已通过 AIBridge 执行 Unity 编译检查。
- 编译结果：0 error，0 warning。
