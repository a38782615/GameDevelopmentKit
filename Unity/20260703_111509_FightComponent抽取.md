# FightComponent抽取

## 改动

- 新增 `FightComponent`，作为战斗场景上的战斗运行组件。
- 将 `UIFormFightSystem.CreateLocalUnitsFromTables` 及其辅助方法迁移到 `FightComponentSystem`。
- `UIFormFightSystem` 打开 UI 时改为通过当前场景的 `FightComponent` 创建本地战斗单位。
- 战斗场景初始化时新增挂载 `FightComponent`。

## 验证

- 已通过 AIBridge 执行 Unity 编译检查。
- 编译结果：0 error，0 warning。
