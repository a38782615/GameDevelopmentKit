# UIFormSkills 技能升级

## 修改内容

- 为 `LevelUp_ExButton` 绑定当前技能升级事件，并在 UI 关闭时移除监听。
- 当前技能存在、拥有下一级 `DTSkillAttribute` 配置且技能经验不少于 `100` 时启用升级按钮。
- 点击升级后扣除 `100` 点 `SkillExp`，调用现有 `PlayerSkillDataComponent.UpgradeSkill` 提升当前技能等级。
- 升级成功后保存玩家数据和技能数据，并刷新技能等级、经验条、经验文本及技能列表。
- 使用 CodeBind 已生成的 `LevelUpExButton` 属性和预制体序列化引用，没有增加手写组件查找。

## 验证结果

- `dotnet build Game.ET.Code.HotfixView.csproj --no-restore` 构建通过，0 错误。
- 通过 Unity Agent Bridge 停止 Play Mode后触发 generation 30 重编译。
- Unity 编译结果为 0 错误、20 个既有警告，本次改动未新增编译诊断。
