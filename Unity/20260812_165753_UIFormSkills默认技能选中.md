# UIFormSkills 默认技能选中

## 修改内容

- 为 `UIFormSkills` 增加当前选中的 `PlayerSkillData` 状态。
- 打开或刷新界面时，默认选中已学技能列表 `Skills_LoopHorizontalScrollRect` 的第一项；已有选择仍保持不变。
- 使用 `SkillExp_Slider`、`SkillExpTxt_UXTextMeshPro`、`SkillName_UXTextMeshPro`、`SkillLevel_UXTextMeshPro` 刷新当前技能详情。
- 点击任一技能列表项时先更新当前选中技能，再执行原有装备切换、存档和列表刷新逻辑。
- 无已学技能时清空详情文本并归零经验条，避免显示预制体默认测试文本。
- 为 `Game.ET.Code.HotfixView` 补充 `GameFramework` 直接程序集引用，确保 Unity 能解析 `Utility.Text.Format`。
