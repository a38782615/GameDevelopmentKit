# UIFormSkills 编译错误修复

## 问题

- Unity 编译 `Game.ET.Code.HotfixView` 时，`UIFormSkillsSystem.cs` 中两处 `GameFramework.Utility.Text.Format` 报 `CS0103`。
- IDE 生成的项目可以构建，但 Unity asmdef 不传递程序集引用，`Game.ET.Code.HotfixView` 没有直接引用 `GameFramework`。

## 修复

- 在 `Game.ET.Code.HotfixView.asmdef` 中增加 `GameFramework` 直接引用。
- 保留项目约定的 `Utility.Text.Format` 字符串格式化方式。

## 验证

- `dotnet build Game.ET.Code.HotfixView.csproj --no-restore` 构建通过。
- 当前未安装或运行 AgentBridge，无法主动触发 Unity Editor 刷新和编译。
