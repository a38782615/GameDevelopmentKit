# UIWidgetMap按钮缓存优化

## 改动

- `UIWidgetMap` 新增 `StageButtons` 和 `StageSubLevels` 缓存字段。
- `UIWidgetMapSystem` 首次绑定时扫描 `P0/P1/P2` 节点并缓存 `ExButton` 与对应 `SubLevel`。
- 后续按钮绑定和解绑直接复用缓存，避免重复遍历 Transform 和重复 `GetComponent`。
- `UIWidgetMap` 销毁时清空缓存，避免对象池复用时持有旧按钮引用。

## 验证

- 已通过 AIBridge 执行 Unity 编译检查。
- 编译结果：0 error，0 warning。
